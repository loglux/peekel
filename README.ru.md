# Peekel

[English version](README.md)

![Far Manager: картинка в быстром просмотре, нарисованная плагином Peekel](docs/images/far-quickview-v2.png)

**Peekel это плагин быстрого просмотра для Far Manager**: нажмите Ctrl+Q и увидите в панели, что это за файл: картинку, SVG, PDF, книгу DjVu,
FB2 или EPUB, начало файла Word, PowerPoint, Excel или OpenDocument, карточку для шрифтов, программ и архивов.

Соседний проект, [Peekel viewer](https://github.com/loglux/peekel-viewer), — просмотрщик файлов для терминала, который ещё и читает
книги PDF, DjVu, FB2 и EPUB: его можно повесить на F3 в Far или в Midnight Commander, в Windows и в Linux.

## Почему он

- **Ctrl+Q работает в Windows Terminal.** Быстрый просмотр Far показывает картинку, документ или карточку в панели, пока вы
  ведёте курсор по файлам.
- **Никакого второго окна.** Peekel рисует графикой Sixel в ячейках самого терминала: ничего не висит поверх консоли, и не
  нужно следить, чтобы оно не съехало; работает и по SSH.
- **Не только картинки.** PDF, книга DjVu, начало файла Word, PowerPoint, Excel или OpenDocument, карточка для шрифта (его же буквами), программы, ZIP:
  тип, размер, даты, что внутри. Когда по имени ничего не понять (обломок `.chk` после восстановления диска), он говорит, что
  это за файл, по содержимому, и предупреждает, если имя и содержимое не совпадают.
- **Испорченные файлы не страшны.** Размер, время и глубина разбора ограничены; сломанный файл даёт сообщение, а не падение.
- **Одна DLL, без среды выполнения.** Написан на Rust. Открытый код, MIT или Apache-2.0.

## Что показывает

| Что | В быстром просмотре |
|---|---|
| PNG, JPEG, GIF (первый кадр), BMP, WebP, TIFF, SVG | картинка |
| RAW-фотографии (NEF, CR2, ARW, DNG, ORF, PEF и другие) | собственный JPEG-превью камеры (в большинстве файлов полного размера), за доли секунды |
| JPEG XL (первый кадр) и DDS (от DXT1 до BC7 и обычные несжатые виды) | картинка; читает сам Peekel, кодек системы не нужен |
| HEIC, AVIF, JPEG XR и всё остальное, для чего в **вашей Windows** есть кодек | картинка, но только там, где кодек установлен (кодеки самой Windows; меню Commands, Plugin commands, «Peekel: formats» показывает, что есть у вас) |
| PDF (текстовые страницы и сканы; без пароля) | первая страница |
| DjVu (отсканированные книги) | первая страница; карточка даёт число страниц и размер страницы (читает собственный читатель, написанный по открытой спецификации формата; пока не читаются: текстовый слой и документы, у которых страницы лежат отдельными файлами) |
| Word (.docx), PowerPoint (.pptx), Excel (.xlsx) | начало, первый слайд, верх листа |
| OpenDocument: текст (.odt), таблица (.ods), презентация (.odp) | начало, верх листа, первый слайд |
| FB2 (и `.fb2.zip`), EPUB (без DRM), HTML | первая страница свёрстанной книги (обложка, если она есть) |
| Шрифты, программы (exe, dll), ZIP, gzip, любой другой бинарный файл | **карточка**: тип, размер, даты; шрифт его же буквами, программа со значком, версией и издателем, ZIP со списком файлов |
| Файлы внутри архива, который показывает ArcLite, 7-Zip и подобные | так же, как для любого файла |

Картинка с цветовым профилем (Display P3, Adobe RGB) переводится в sRGB, поворот из EXIF учитывается. **Документы показываются как
превью, а не как копия**: слова переносятся «на глаз», а диаграммы, текстовые рамки, колонтитулы и многое другое не рисуются.
Текст в SVG и документах рисуется установленными на компьютере шрифтами; если документ просит шрифт, которого нет, будет другой.

### Форматы из Windows (WIC)

HEIC, AVIF, JPEG XR, иконки и подобные файлы открывают кодеки **вашей Windows** (Windows Imaging Component, WIC), а не
собственный код Peekel. Поэтому, что откроется, зависит от компьютера: часть кодеков есть в самой Windows (JPEG XR, иконки
и другие), а остальные это расширения из Microsoft Store (HEIF и другие), которых может не быть. JPEG XL и DDS читает сам Peekel.

- **Что открывает ваш компьютер:** в Far меню Commands, Plugin commands, «Peekel: formats» показывает список. (F11 открывает то
  же меню, но Windows Terminal забирает F11 под полный экран.)
- **Когда кодека нет:** карточка файла HEIC или AVIF говорит об этом и называет расширение Microsoft Store, которое может
  его добавить. Пока показана такая карточка, **Ctrl+Alt+S** открывает Store на странице этого расширения; ставить его или нет,
  решаете вы, Peekel ничего не устанавливает.
- То, что Peekel читает сам (PNG, JPEG, RAW по превью и остальное из таблицы выше), от этого не зависит.

## Установка

Возьмите архив из [последнего выпуска](../../releases/latest): `Peekel-<версия>-windows-x64.zip`. К нему приложен файл `.sha256`:
сверьте его. Нужен Far 3.0 (64-разрядный) в терминале с Sixel: **Windows Terminal 1.22 или новее**, либо xterm, mlterm, foot и
другие. **ConEmu не поддерживается**: он не показывает Sixel (самая новая версия, 230724 от июля 2023, не рисует картинку) и больше
не развивается.

Закройте Far и запустите `install.ps1` из архива. Он сам находит Far; если не нашёл или нашёл несколько, укажите:
`.\install.ps1 -Far 'C:\Tools\Far'`. `-Uninstall` удаляет плагин, `-WhatIf` показывает, что будет сделано. Вручную: скопируйте папку
`Peekel` в папку `Plugins` рядом с `Far.exe` (или в `%APPDATA%\Far Manager\Profile\Plugins`). Запустите Far, нажмите Ctrl+Q и ведите
курсор по файлам. Peekel может конфликтовать с другими плагинами, которые обрабатывают быстрый просмотр (Ctrl+Q).

Из исходников: установите Rust (версия в `rust-toolchain.toml`) и выполните `cargo build --release -p peekel-far`; плагин:
`target/release/peekel_far.dll`.

## Как пользоваться

Нажмите Ctrl+Q в панели, чтобы другая панель стала быстрым просмотром, и ведите курсор: картинка, документ или карточка рисуются в
рамке поверх текста, который Far напечатал бы там; текстовые файлы Far показывает как обычно. **Ctrl+Alt+I** показывает карточку файла (вид, размер, даты, EXIF фотографии)
вместо картинки; повторное нажатие возвращает картинку. Если что-то не так, задайте
переменную окружения перед запуском Far:

| Переменная | Что делает |
|---|---|
| `PEEKEL_FAR_LOG=<файл>` | плагин пишет в этот файл, что делает (приложите к сообщению об ошибке) |
| `PEEKEL_OFF=hook` | выключает плагин, не удаляя его |
| `PEEKEL_CELL=10x20` | отключает запросы плагина к терминалу; размер ячейки вычисляется по окну |
| `PEEKEL_REAL_CELL=13x28` | размер ячейки вручную, если плагин не может вычислить его по окну |
| `PEEKEL_BG=#0037DA` | цвет панелей в HEX-формате; используется, когда терминал не спрашивается |

Окна настроек пока нет; если захотите что-то отключить, скажите что.

## Выключите «ClearType friendly redraw»

В Far: F9 › Options › Interface settings, снимите «ClearType friendly redraw» и нажмите OK.
(В `far:config` это `Interface.ClearType`.)

Зачем. Когда эта настройка включена, Far перерисовывает ряд экрана целиком, если в нём хоть что-то изменилось. При движении курсора
в панели ряды полоски курсора перерисовываются на всю ширину экрана, терминал стирает часть картинки, которая на них лежит, и картинку
пересекают полосы, пока её не нарисуют заново. Когда настройка выключена, Far перерисовывает только изменившееся и картинку не трогает;
окно, открытое поверх картинки, тоже оставляет её целой вокруг себя.

По исходникам Far, эта настройка нужна против тонких полосок, которые оставляло сглаживание шрифтов ClearType в классической консоли
Windows. Плагин в классической консоли не работает (ему нужен терминал, который рисует Sixel, например Windows Terminal 1.22 или новее),
а Windows Terminal рисует текст сам: там, где работает плагин, эта настройка ничего полезного не делает. Пока она включена, плагин
показывает короткую подсказку в быстром просмотре и в своём окне (F11 › Peekel: formats).

## Работа с макросом на Esc

Чтобы нарисовать картинку правильного размера, плагин спрашивает у Windows Terminal размер ячейки знакоместа в пикселях и цвет панелей (на этот цвет картинка кладётся, чтобы вокруг неё не было полосы другого цвета). Терминал отвечает последовательностями, которые начинаются с Esc. Размер ячейки Windows Terminal сообщает всегда один, 10×20, при любом шрифте, а настоящий размер зависит от шрифта и масштаба экрана (например, Consolas при 150 % даёт 13×28). Поэтому плагин вычисляет настоящий размер сам, по окну терминала, из данных Windows.

Макрос `Panel.Esc.lua` (по Esc прячет и показывает панели) мешает этому обмену. Ответы терминала начинаются с Esc, а макрос срабатывает на Esc. Чтобы совместить макрос с плагином, задайте до запуска Far две переменные из таблицы выше:

- `PEEKEL_CELL=10x20`: плагин перестаёт спрашивать терминал, а размер ячейки по-прежнему вычисляется по окну.
- `PEEKEL_BG=#0037DA`: цвет панелей вашей темы в HEX-формате. Без неё берётся тёмно-синий `#000080`, и у края картинки может быть видна полоса.

Переменные задаются в окне PowerShell, и Far запускается из этого же окна (вместо `<путь к Far.exe>` подставьте путь к вашему Far):

```powershell
$env:PEEKEL_CELL='10x20'; $env:PEEKEL_BG='#0037DA'; & "<путь к Far.exe>"
```

Если вы не знаете цвет панелей, его можно взять из лога плагина. Для этого один раз запустите Far **без макроса** (отключите его на этот запуск: пока плагин спрашивает терминал, макрос ему мешает) и без `PEEKEL_CELL`, но с переменной `PEEKEL_FAR_LOG`, которую тоже задайте в PowerShell, запустив Far из этого же окна:

```powershell
$env:PEEKEL_FAR_LOG="$env:TEMP\peekel.log"; & "<путь к Far.exe>"
```

Откройте картинку в быстром просмотре, подождите секунд двадцать и закройте Far. В файле `peekel.log` строка «the terminal says its colours are […]» перечисляет цвета палитры терминала (красный, зелёный, синий); синий Far пятый по счёту (номер 4, считая с нуля), например `[0, 55, 218]`. Запишите его в HEX (`#0037DA`) или через запятую (`0,55,218`), включите макрос обратно и задайте `PEEKEL_BG`.
